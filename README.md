# 📦 Sistema de Estoque em Python

Sistema de gerenciamento de estoque desenvolvido em Python como projeto de portfólio para prática de programação e desenvolvimento de sistemas.

O projeto simula operações básicas de um sistema de estoque, permitindo cadastrar produtos, controlar entradas e saídas, consultar produtos e acompanhar níveis de estoque.

---

## 🚀 Funcionalidades

- ✅ Cadastro de produtos
- 🔎 Busca de produtos por código
- 📋 Listagem de produtos
- ➕ Entrada de estoque
- ➖ Saída de estoque
- ⚠️ Alerta de estoque baixo
- 🗑️ Exclusão de produtos
- 💰 Controle de preço unitário
- 📊 Relatório geral do estoque
- 🛡️ Validação de dados
- 🆔 Código único para produtos
